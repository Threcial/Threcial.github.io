复杂文本处理-grep sed awk

发表于2026-05-24|更新于2026-05-24|linux
|浏览量:

grep：找出符合条件的行，核心思路是：哪些行符合条件

sed：对行内容进行增删改查，核心思路是：按规则修改某些行

awk：按列处理文本，核心思路是：按字段、按列提取或计算数据，适合处理有规律的字段
