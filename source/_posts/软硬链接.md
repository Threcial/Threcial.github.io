链接文件是linux下的文件类型之一，包括软链接和硬链接

软链接相当于快捷方式，而硬链接相当于另一个文件名，具体区别如下

|  |  |
| --- | --- |
| 软链接 | 硬链接 |
| 可以链接目录 | 不能链接目录 |
| ln -s创建 | ln创建 |
| Inode不同 | Inode相同 |
| 删除源文件失效 | 删除源文件无影响 |

跨目录创建软链接需要使用绝对路径

通过ls的-i选项可以查看Inode号，file和stat查看更加详细的信息
