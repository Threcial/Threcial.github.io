这里是 **Threcial** 的技术笔记站点。

原站为 [threcial.cn](https://threcial.cn)（WordPress + Sakurairo 主题），本站是其内容镜像，
以 Hexo + Butterfly 主题生成，托管在 GitHub Pages 上，用于原站不可用时的访问。
内容与原站保持一致，不含评论等需要后端的交互功能。

## 内容方向

- **Linux 系统管理** —— 系统配置、性能优化、常用工具与文本处理
- **计算机网络** —— OSPF、RIP、DHCP、FTP 等协议与网络原理
- **数据库** —— MySQL 基础语句、函数、事务与主从复制
- **Web 服务** —— Nginx、Tomcat 等服务的配置与调优
- **网络安全** —— 安全基础、等级保护、防御设计与风险评估
- **CTF / 密码学** —— 竞赛题解与密码学笔记

## 关于本站

- 构建方式：Hexo 静态生成，无后端、无数据库
- 主题：[hexo-theme-butterfly](https://github.com/jerryc127/hexo-theme-butterfly)
- 源码托管：[Threcial/Threcial.github.io](https://github.com/Threcial/Threcial.github.io)
